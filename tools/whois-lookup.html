Enter a domain above and click Lookup.

⚙️How it works

Queries the modern WHOIS via public RDAP (the registry API that has replaced the old WHOIS) — rdap.org first (CORS-enabled), falling back to rdap.verisign.com for .com/.net when needed. The record shows the registrar, created/updated/expiry dates, domain status flags, nameservers and any published contacts. The 📄 Raw RDAP button opens the full JSON record in a new tab.

🔒Privacy

Only the domain you enter is shared with the registry's public API — and nothing is stored or tracked.

💡Tips
  • Contact fields showing "Redacted (GDPR)" is normal registrar policy — not a tool limitation.
  • Every TLD has its own RDAP provider; rdap.org routes automatically, and Verisign covers .com/.net.
  • Registration dates come straight from registry data, making this the authoritative source for domain age too.
