Ping Test

Measure HTTP round-trip time to any URL. Uses timestamped HEAD requests to simulate ping rounds — results show per-ping latency and aggregate stats.

Network client-side

Result

Enter a URL and click Start Ping Test.

⚙️How it works

Sends one HEAD request per round to your URL with a no-cors, no-store cache-buster query (?_ping=timestamp) so repeat pings aren't served from a cache. Each round's round-trip time is measured from your browser; a 5-second timeout marks a round as lost. Results are summarised as min, avg, max, jitter (max − min), packet loss %, a verdict and a per-round table and bar chart.

🔒Privacy

This is an application-layer ping — requests go straight from your browser to the target (not ICMP, and no server or proxy in between).

💡Tips
  • If you omit the scheme, https:// is added for you.
  • Because of no-cors, the round-trip is still measurable across origins — good for testing any public site.
  • High jitter means connection stability issues; run with a higher count for a steadier average.
